# Feedback Management System

A Full Stack Feedback Management System developed using Spring Boot and MySQL. Users can submit feedback through a web form, and the data is stored securely in a MySQL database.

## Features

- Submit feedback form
- Store feedback in MySQL database
- REST API integration
- Responsive UI using Bootstrap
- Spring Boot backend
- Maven project structure

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Maven

## Project Structure

Frontend → REST API → Spring Boot Backend → MySQL Database

## How to Run

1. Clone repository
2. Configure MySQL in application.properties
3. Run the Spring Boot application
4. Open:
   http://localhost:8080
